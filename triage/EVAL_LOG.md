# Eval log

Eval sets: hand-labeled CloudTrail events in `eval_cases.json` (16 cases, scored out of 16), and cases with designed related events in `eval_context_cases.json` (8 cases, tagged `[context set]`, scored out of 8). New rows are added by `python -m triage.evals --log "what changed"`.

**Prompt** is a fingerprint of the system prompt: runs with the same value used the same prompt. Early runs were logged by hand, before fingerprints existed.

**Too low** and **Too high** count ratings that missed the label in each direction. Too low matters more for security: it means a real problem would sit lower in the queue than it should. **Failed** counts calls that returned no usable result. **Cost per 1,000 alerts** and **Avg time per alert** are averaged over the calls that succeeded, using the token prices in `triage/triage.py`. Runs before 2026-10-16 didn't record cost, time or failures, and runs before 2026-10-17 didn't record direction (—).
